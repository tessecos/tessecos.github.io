# Tessecos Studio — website

Static bilingual website of Tessecos Studio (independent development team), hosted on GitHub Pages.

- `/` — studio homepage, lists our games.
- `/privacy/`, `/support/`, `/app-ads.txt` — Tessecos / 归序 (the studio's first game). These stay at the site root.
- `/fewest-pop/` — Fewest Pop / 最少先爆: about page, `privacy/`, `support/`.
- Every further game gets its own folder like `/fewest-pop/`.

Support: tessecos@gmail.com

This repository contains only the public website; it does not contain game source or player data. The website has no advertising or analytics scripts. `app-ads.txt` lists Google AdMob as the authorized seller for Tessecos' rewarded ads (Fewest Pop has no ads).

Note: the Tessecos pages are generated by `website/tessecos-support/build.py` in the Tessecos game repository. Its `dist/` still contains a Tessecos `index.html`; when publishing Tessecos updates, copy only `privacy/`, `support/`, `assets/app-icon.png` and `app-ads.txt`, so the studio homepage and `assets/styles.css` (game-card styles added at the end) are not overwritten.
