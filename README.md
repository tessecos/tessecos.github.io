# Tessecos Studio — website

Static website of Tessecos Studio (independent development team), hosted on GitHub Pages.

- `/` — studio homepage: hero plus one clickable card per game, each opening the game's page.
- `/tessecos/` — Tessecos / 归序 game page (cover, features, screenshots).
- `/privacy/`, `/support/`, `/app-ads.txt` — Tessecos / 归序 (the studio's first game). These stay at the site root.
- `/fewest-pop/` — Fewest Pop / 最少先爆 game page, `privacy/`, `support/`.
- Every further game gets its own folder like `/fewest-pop/`.

Support: tessecos@gmail.com

This repository contains only the public website; it does not contain game source or player data. The website has no advertising or analytics scripts. `app-ads.txt` lists Google AdMob as the authorized seller for Tessecos' rewarded ads (Fewest Pop has no ads).

Note: the Tessecos pages are generated by `website/tessecos-support/build.py` in the Tessecos game repository. Its `dist/` still contains a Tessecos `index.html`; when publishing Tessecos updates, copy only `privacy/`, `support/`, `assets/app-icon.png` and `app-ads.txt`, so the studio homepage is not overwritten. Studio and game pages use `assets/site.css` on top of the unchanged Tessecos `assets/styles.css`.

Language: studio and Fewest Pop pages show one language. `assets/lang.js` picks Chinese when the browser's first language is Chinese, English otherwise; the nav button switches and remembers the choice. Mark language-specific elements with `class="en"` / `class="zh"`. The Tessecos privacy/support pages are still bilingual (generated by build.py).
