# Tessecos / 归序 — Privacy & Support

Static bilingual privacy and player support website for Tessecos.

Developer team: Tessecos Studio (independent development team).
Support: tessecos@gmail.com

This repository contains only the public website; it does not contain the game source or player data. Hosted on GitHub Pages. The website has no advertising or analytics scripts. `app-ads.txt` lists Google AdMob as the authorized seller for the game's rewarded ads.
