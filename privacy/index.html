隐私政策

更新日期：2026-10-21 · 适用于 Tessecos / 归序 1.0.0

无需创建游戏账号，核心玩法离线运行。

存档保存在当前设备，不向开发者上传，也不通过云端同步。

Apple 负责购买与恢复购买；游戏使用 Google AdMob 提供可选激励广告。

1. 开发团队与适用范围

本政策说明由 Tessecos Studio 独立开发团队维护的 Tessecos / 归序游戏及本网站如何处理数据。隐私问题可通过下方支持邮箱联系。

2. 设备中的游戏数据

关卡、棋盘与操作历史、用时、生成地图、通关记录、道具数量、主题和语言、声音、外观偏好保存在应用的本地目录。开发者无法远程读取这些存档。

3. Apple 内购服务

游戏使用 Apple StoreKit 2 查询商品、核验全部皮肤包和去广告权益，并恢复购买。两项均为一次性非消耗型商品。Apple 处理支付与交易；游戏不会读取 Apple 密码或银行卡信息，只接收商品信息与核验结果。权益不通过云端保存的购买标记授予。

Apple 服务适用 Apple 隐私政策。

4. 广告与权限

游戏提供主动观看激励广告获取当局道具的入口。广告由 Google AdMob 提供，仅在主动点击后请求。广告服务可能处理 IP 地址、设备标识、广告交互、崩溃和性能诊断数据；详见 Google 隐私政策及 Google SDK 数据披露。需要时由 Google 的隐私消息收集选择。游戏不请求相机、麦克风、定位或通讯录权限。广告不可用或未获得 SDK 领奖确认时不发奖励。

5. 保存与恢复

进度和道具保存在本机，没有跨设备存档同步。删除应用及其数据可能丢失进度；系统备份是否可恢复取决于设备设置。广告获得的道具绑定当前对局，重开或换关失效，继续同一存档局面仍有效。

全部皮肤包和去广告权益可使用原购买 Apple 账号在商店点击“恢复购买”核验；恢复权益不会恢复本机棋盘或道具记录。

6. 支持邮件

如果你主动发送支持邮件，运营者会收到你的邮箱地址、邮件内容及你主动附上的截图或设备信息，仅用于回复和处理请求。请勿发送密码、完整付款凭证或其他不必要的敏感信息。支持邮件仅在处理问题及适用要求所需的期间保留；你可以通过支持邮箱提出访问或删除请求。

7. 本网站与外部链接

本网站是静态页面，没有广告、分析脚本、登录系统或在线表单。网站由 GitHub Pages 托管；GitHub 会为安全目的记录访问者 IP 等技术信息，具体请参阅 GitHub Pages 数据说明和 GitHub 隐私声明。

访问 Apple、GitHub 等外部网站时，相应网站和浏览器会按各自政策处理访问数据。

8. 政策更新

若应用的数据处理方式发生变化，将更新本政策及必要的商店隐私说明，并标明更新日期。

Privacy policy

Updated: 2026-10-21 · Applies to Tessecos / 归序 1.0.0

No game account is required. Core gameplay works offline.

Saves stay on the current device and are neither uploaded to the developer nor synced through the cloud.

Apple handles purchases and restoration. The game uses Google AdMob for optional rewarded ads.

1. Developer team and scope

This policy describes data handling for Tessecos / 归序 and this support website, maintained by the independent team Tessecos Studio. Contact the support email below for privacy questions.

2. Local game data

Levels, boards and action history, elapsed time, generated maps, completion records, tool counts, themes, and language, audio and appearance preferences stay in the app’s local directory. The developer cannot remotely read these saves.

3. Apple purchases

Apple StoreKit 2 queries products, verifies ownership and restores the All Skins Pack and Remove Ads. Both are one-time non-consumable purchases. Apple handles payments and transactions. The game does not read Apple passwords or payment-card details; it receives product information and verified results. Cloud purchase flags never grant ownership.

Apple services follow the Apple Privacy Policy.

4. Advertising and permissions

The game provides optional rewarded-ad buttons for tools that last for the current run. Ads are provided by Google AdMob and are requested after an explicit user action. The service may process IP addresses, device identifiers, ad interactions, crash reports and performance diagnostics; see the Google Privacy Policy and Google SDK data disclosure. Google privacy messages collect choices when required. The game requests no camera, microphone, location or contacts access. Unavailable ads or ads without an SDK-earned reward grant nothing.

5. Saves and recovery

Progress and tools stay on the device, with no cross-device save sync. Deleting the app and its data may lose progress; system backup recovery depends on your device settings. Ad tools belong to the current run, expire on restart or level change, and remain valid when continuing the same saved run.

Restore Purchases in the shop can verify the All Skins Pack and Remove Ads with the original purchasing Apple Account. Restoring ownership does not recover local boards or tool records.

6. Support email

If you email support, the operator receives your email address, message and any screenshots or device information you choose to include, solely to respond and handle your request. Do not send passwords, full payment records or unnecessary sensitive information. Support messages are kept only as needed to resolve requests and meet applicable requirements. Contact support to request access or deletion.

7. This website and external links

This is a static website with no ads, analytics scripts, sign-in system or web forms. GitHub Pages hosts the site. GitHub logs visitors’ IP addresses and technical information for security; see GitHub Pages data collection and the GitHub Privacy Statement.

When you visit external Apple or GitHub pages, those websites and your browser process visits under their own policies.

8. Changes

If data handling changes, this policy and necessary App Store privacy disclosures will be updated, with a revised date.
